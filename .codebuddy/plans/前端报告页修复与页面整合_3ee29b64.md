## 用户需求

1. 修复前端「分析报告结果看不到」的问题（包括无数据引导生成、图表渲染可能白屏、入口分散等）。
2. 将「AI建议页面」与「AI分析页面」整合到同一个「AI建议页面」中，采用合理的整合方式（子标签/分栏切换）。
3. 将「打卡提醒」以不突兀的小窗格形式引入首页。
4. 仅制定计划，不实施。

## 产品概述

重构前端三处入口：统一 AI 能力为单页（AI建议页 = 对话建议 + 分析报告两个子视图切换），修复分析报告渲染与数据引导问题，并在首页以玻璃拟态小窗格嵌入今日打卡提醒，保持首页视觉一致、不喧宾夺主。

## 核心功能

- 整合页：AI建议页内部分两个子视图「对话建议」（现有聊天）与「分析报告」（现有分析），顶部子 Tab 切换；分析报告视图在「无报告」时给出醒目「生成分析报告」引导按钮，触发 /generate 后轮询直到完成，charts 为空时渲染占位而非白屏。
- 修复可见性：移除 HomeView 中重复的 ai-analysis 内嵌与独立 /ai-analysis-report 路由，分析报告统一经整合页访问；ECharts 用 v-if + 默认值保护，避免空数据导致整页报错。
- 首页提醒小窗格：抽取 ReminderWidget 小组件，半透明玻璃卡片展示今日/启用的打卡提醒（按类型分组、可一键跳转提醒管理），视觉轻量不占主视觉。

## 技术栈选择

- 前端：Vue 3 + Vite + Element Plus + ECharts + vue-echarts，沿用现有 frontend 结构与 request.js 封装；沿用 Tailwind 玻璃拟态（glass）+ 蓝色主调风格。
- 后端：Spring Boot（AI分析接口 /api/ai-analysis/*、提醒接口 /api/reminders 已就绪，本次仅前端整合，不改动后端逻辑；如需仅前端修复则后端零改动）。

## 实现方案

### 1. 整合「AI建议页 + AI分析页」

- 以 `AiChatView.vue`（对话建议）为整合载体，或新建 `AiAdviceView.vue` 作为统一容器；页面顶部增加子 Tab：「对话建议」「分析报告」。
- 复用现有 `AiChatView` 的会话/聊天逻辑作为「对话建议」子视图；复用现有 `AiAnalysisView` 的分析报告逻辑作为「分析报告」子视图（提取为子组件或 section，保留评分环、结构化结论卡片、建议、Markdown、ECharts、历史列表）。
- 移除 `HomeView.vue` 中 `mainTabs` 的 `ai-analysis` 内嵌项（避免与独立页重复、逻辑脆弱）；删除路由 `/ai-analysis-report`，将 `/ai-analysis-report` 重定向到整合页的「分析报告」子视图（用 query 或 hash 定位 tab）。

### 2. 修复「分析报告看不到」

- 分析报告子视图：进入时调用 `aiAnalysis.getLatest()`；若返回 null 或无 COMPLETED 任务，显示占位引导卡（含「生成 N 天分析报告」按钮 → `aiAnalysis.generateAnalysis(days)` 拿到 taskId 后轮询 `getTask(id)` 直到 COMPLETED/FAILED，再展示结果）。
- ECharts 安全渲染：趋势/雷达 `VChart` 外层统一加 `v-if="task?.charts?.trend || task?.charts?.radar"`，否则显示「图表生成中/暂无数据」占位；computed 中对 `indicators/values` 做空数组兜底，防止 `toArr` 在 undefined 时抛错。
- 结构化字段（score/dailyEvaluation/trendSummary/riskWarning/suggestion）已有，正常展示；report 用 `<pre>` 展示，无数据时显示提示。

### 3. 首页打卡提醒小窗格

- 新建 `frontend/src/components/ReminderWidget.vue`：挂载时 `reminderApi.listReminders()`，筛选 `isActive` 且为「今日到期」的提醒（按 weekday 含当天或一次性未过期），按类型分组展示为小卡片（图标/标题/时间），底部「管理提醒」按钮跳 `/reminder`。
- 玻璃拟态小窗格（glass 卡片、半透明、与首页卡片同款圆角与配色），置于首页某一区块（如任务目标区下方或侧边），不插入首屏主视觉。
- `HomeView.vue` 引入 `ReminderWidget` 并渲染；复用现有 `api/reminder.js` 与 `TYPE_MAP` 风格（与 ReminderView 视觉一致）。

### 4. 路由与导航一致性

- `router/index.js`：保留 `/ai-advice`（整合页，承载对话+报告）；删除或重定向 `/ai-analysis-report`；`document.title` 统一为「AI 建议」。
- 导航菜单（MainLayout）：将「AI分析」「AI建议」合并为单一「AI建议」入口（或保留但指向整合页），消除重复。

## 实现注意事项

- 不改动后端任何代码与 PRD；仅前端文件调整（符合用户「不使用那份文档技术栈、仅满足功能」）。
- 整合页内子视图切换用本地 `ref activeTab`，不引入路由嵌套，降低复杂度与回归风险。
- ECharts 渲染必须防御空数据，确保任何状态下页面不白屏（最高优先级修复项）。
- 复用现有 `api/aiAnalysis.js`、`api/reminder.js`、`api/chat.js`、`api/session.js` 与全局 `request.js`，不重复封装。
- 组件拆分：分析报告视图从 `AiAnalysisView` 抽取为 `AiReportSection.vue`（或保留在本页但被整合页引用），保证单一职责与可复用。
- 每次有效修改后按项目约定 git 提交并推送 origin/main。

## 关键代码结构（可选）

- `AiAdviceView.vue` 容器骨架（仅示意结构，不写实现）：
- `const activeTab = ref('chat')` // 'chat' | 'report'
- 顶部子 Tab 切换：对话建议 / 分析报告
- 对话建议区：`<AiChatView />`（或提取的聊天 section）
- 分析报告区：`<AiReportSection @generate="..." />`（含 getLatest + 生成引导 + ECharts 安全渲染）
- `ReminderWidget.vue` 公开方法/事件：
- `onMounted` 调 `reminderApi.listReminders()`
- 计算属性 `todayReminders`：过滤 `isActive && 今日到期`
- 点击「管理提醒」`router.push('/reminder')`

基于现有前端玻璃拟态（glass）+ 蓝色主调风格进行整合，不引入新视觉语言。整合页采用顶部子 Tab 切换「对话建议 / 分析报告」，与现有 AiChatView 头部风格一致；分析报告区沿用评分环、结构化结论卡片、ECharts 卡片网格；首页提醒小窗格使用与首页统计卡同款的 glass 圆角卡片、半透明背景、轻量阴影，置于次要位置不干扰首屏主视觉。
