# Agent Demo 需求文档

## 1. 文档说明

### 1.1 文档名称

Agent Demo 需求文档

### 1.2 文档目的

本文档用于明确 Agent 类全栈 Demo 的建设目标、功能范围、技术约束、交付标准与开发边界，供开发人员在两周周期内完成原型系统开发与演示。

### 1.3 适用对象

- 开发人员
- 项目指导人员
- Demo 演示人员

### 1.4 开发周期

预计开发周期为 2 周。

### 1.5 技术约束

- 后端以 `Spring Boot` 技术栈为核心
- 可使用 `Spring Web`、`Spring Data JPA`、`MySQL`、`Thymeleaf`
- 可引入少量辅助技术栈，如 `Redis`、`Spring AI`、`ECharts`
- 不要求复杂微服务架构
- 不要求本地大模型部署
- 不要求多 Agent 协作框架

##  项目：生活习惯助手 Agent

### 4.1 项目背景

用户希望记录自己的生活习惯，并根据历史数据获得个性化建议。该 Demo 旨在通过记录用户每日作息、饮食、运动等信息，结合 AI 给出分析结果与改善建议。

### 4.2 项目目标

构建一个支持习惯记录、历史查看、趋势分析和 AI 建议输出的 Web 系统，体现 Agent 对动态数据的持续分析能力。

### 4.3 目标用户

- 有健康管理需求的普通用户
- 希望养成良好习惯的学生或上班族

### 4.4 功能范围

#### 4.4.1 必做功能

- 支持每日录入作息数据
- 支持每日录入饮食与运动数据
- 支持查看历史记录
- 支持根据历史记录生成 AI 分析结果
- 支持输出生活习惯改善建议

#### 4.4.2 可选功能

- 支持打卡提醒
- 支持周报/月报统计
- 支持图表展示趋势
- 支持自定义习惯目标
- 支持达成率统计

### 4.5 业务流程

1. 用户每天录入习惯数据
2. 系统保存每日记录
3. 用户查看个人历史数据
4. 用户发起分析请求
5. AI 基于一段时间内的数据输出总结与建议

### 4.6 页面需求

- 首页/欢迎页
- 每日打卡页
-  历史记录页
- 趋势分析页
- AI 建议页

### 4.7 数据需求

#### 4.7.1 输入数据

- 睡眠时间
- 起床时间
- 饮食情况
- 运动情况
- 饮水情况
- 备注信息

#### 4.7.2 输出数据

- 每日评价
- 周期趋势总结
- 生活习惯风险提示
- 改善建议

### 4.8 非功能要求

- 数据录入流程简单
- 历史数据可持续累积
- 页面展示应直观清晰
- 系统适合做连续性演示

### 4.9 技术建议

- 后端：`Spring Boot`、`Spring Web`、`Spring Data JPA`
- 数据库：`MySQL`
- 前端：`Thymeleaf + Bootstrap`
- 可选：`ECharts`
- AI 能力：模型 API 或 `Spring AI`

## 5. 通用交付要求

### 5.1 交付内容

- 可运行的源代码
- 数据库建表脚本
- 项目启动说明
- 功能演示说明
- 简单测试数据

### 5.2 演示要求

- 可完成核心流程演示
- 页面具备基本可用性
- 数据能够正常保存和读取
- AI 结果能够正常展示

### 5.3 开发边界

- 不要求复杂权限系统
- 不要求复杂消息队列
- 不要求分布式部署
- 不要求多端适配
- 不要求复杂算法优化
