## 〇、系统架构总览（已落地 + 规划）

### 架构分层

```
前端 frontend/ (Vue3 + Vite 单仓库 SPA)
  └─ Axios 调 /api + EventSource 收 SSE（Vite 代理 /api → 后端 8080）
            │
后端 habit-agent (Spring Boot 4.1 + Spring AI 2.0)
  └─ Controller 层（纯 REST/SSE）→ Service 层（业务）→ Repository 层
        ├─ JPA Repository → MySQL（业务数据：用户/习惯记录/目标）
        └─ Mongo Repository → MongoDB（AI 数据：对话记忆/分析结果/向量）
              └─ MongoDB Atlas VectorStore（RAG 知识库）
  └─ Agent 层（ChatClient + 工具 + Advisor + 多智能体路由）→ 通义千问 DashScope
```

## 二、阶段详解（已落地模块据实描述，待开发模块给出规范）

### 阶段一：环境搭建与项目骨架 ✅ 已落地
- 技术点：Spring Boot 4.1 + JDK 21 + Spring AI 2.0 BOM；Maven 多依赖（Web / JPA / MySQL / MongoDB / spring-ai-openai / mongodb-atlas-vector-store）。
- 双库就绪：MySQL `habit_agent` + MongoDB `habit_agent`（本地或 Docker）。
- 通义千问通过 DashScope OpenAI 兼容端点接入（application.yml `spring.ai.openai.base-url=https://dashscope.aliyuncs.com/compatible-mode`）。
- Git 仓库已初始化，远程 `https://github.com/Yu-xingyou/Agent_demo`。

### 阶段二：业务数据层（MySQL）✅ 已落地

#### 2-1 用户与习惯记录（HabitController，7 端点）
- Entity：`HabitRecord`（sleepTime/wakeTime/sleepDuration/sleepQuality/dietDesc/dietScore/exerciseType/exerciseDuration/waterIntake/mood/remark）。
- Repository：`HabitRecordRepository`（JPA，`uk_user_date` 唯一约束，每日打卡幂等）。
- Service：`HabitService`；Controller：`HabitController`（`/api/habits`，7 端点：今日/列表/按日期/创建/更新/删除/统计）。
- 验收：录入 → 查询 → 同日重复录入为更新。

#### 2-2 习惯目标管理（GoalController 目标 CRUD，8 端点）✅ 已落地
- **枚举（真实代码）**：
  - `goalType`：`SLEEP` / `EXERCISE` / `WATER` / `DIET` / **`CUSTOM`**（自定义目标，正式纳入 PRD 口径）。
  - `period`：`DAILY` / `WEEKLY` / `MONTHLY`（实体枚举；VO 通过 `.name()` 输出，前端按字符串展示）。
- **HabitGoalVO 字段**（与代码严格一致）：
  `id`、`userId`、`goalType`、`customName`（CUSTOM 时必填，目标名称）、`displayName`（CUSTOM→customName，其余→goalType 中文/枚举）、`targetValue`(BigDecimal)、`unit`、`period`、`isActive`、`createTime`、`updateTime`、`currentValue`（本周累计值）、`weeklyAchievement`（本周达成率 %）。
- Entity：`HabitGoal`（goalType VARCHAR、targetValue DECIMAL、unit、period 默认 DAILY、isActive）。
- 端点（`/api/goals` 前缀，8 端点）：列表 / 详情 / 创建 / 更新 / 删除 / 启用切换 / 活跃目标（含 CUSTOM）/ 按类型查询。
- 自定义目标特殊处理：`goalType=CUSTOM` 时由 `customName` 提供展示名，`displayName` 自动回退；`currentValue` 与 `weeklyAchievement` 由打卡记录聚合计算。
- 验收：创建 SLEEP 目标；创建 CUSTOM 目标（带 customName）；查询返回 displayName 与本周达成率。

#### 2-3 自定义目标打卡记录（GoalController `/api/goal-records`，6 端点）✅ 已落地【正式功能】
- **说明**：原为超纲扩展，现提升为正式功能模块（agent 模型「自定义习惯目标（可选）」的落地实现）。
- 端点（`/api/goal-records/records` 前缀，6 端点）：
  - `POST /api/goal-records/records`：录入/更新自定义目标打卡（`@Valid`：goalId、recordDate 必填）
  - `GET /api/goal-records/records/today`：今日所有自定义目标打卡
  - `GET /api/goal-records/records?startDate=&endDate=`：日期范围查询
  - `GET /api/goal-records/records/recent/{days}`：最近 N 天打卡
  - `GET /api/goal-records/records/goal/{goalId}/recent/{days}`：按目标查最近 N 天
  - `GET /api/goal-records/records/goal/{goalId}/achievement?period=WEEKLY`：按目标/周期查达成率（驱动 VO 的 `weeklyAchievement`）
- 请求体示例：
  ```json
  POST /api/goal-records/records
  { "goalId": 1, "recordDate": "2026-08-02", "value": 10000, "remark": "完成" }
  ```
- 验收：录入 CUSTOM 目标打卡 → 查询今日/范围 → 目标 VO 的 currentValue/weeklyAchievement 同步更新。

### 阶段三：前端工程（Vue3 + Vite 单仓库）✅ 已落地
- 5 路由：HomeView / CheckinView / HistoryView / TrendView / AiChatView。
- Axios 封装 `utils/request.js` 统一解析 `Result`；Vite `server.proxy['/api']` → `http://localhost:8080`。
- 打卡表单提交 `POST /api/habits`；历史页 `GET /api/habits`；首页今日统计 `GET /api/habits/today`。

### 阶段四：Spring AI 基础对接（技术点 1/2/4/6）✅ 已落地
- 目标：ChatClient Bean 配置、`defaultSystem` 设定「生活习惯助手」人格、通义千问连通验证。
- 产出（已落地）：
  - `config/ChatClientConfig.java`：构建全局 `ChatClient` Bean，从 `classpath:prompts/system-prompt.st` 注入系统提示词；`defaultOptions` 复用 `application.yml` 的 `qwen-plus` / `temperature=0.7`；含启动连通性探针 `ChatConnectivityProbe`（ping 通义千问，失败仅 WARN 不阻断启动）。
  - `resources/prompts/system-prompt.st`：系统提示词模板（助手人格 / 职责 / 边界 / 语气）。
  - `service/ChatService.java`：骨架，`chat(String)` 非流式 + `stream(String)` 流式（返回 `Flux<String>`），预留阶段五/六/七/九 扩展点；本阶段零对外端点。
- 验证：应用启动日志出现 `[阶段四] 通义千问连通性验证成功`，或 `WARN` 提示（无 Key 时）。模型/Key 配置见 `application.yml` 的 `spring.ai.openai`。

### 阶段五：对话记忆与流式输出（技术点 5/11/12）✅ 已落地
- 5-1 记忆（已落地）：`config/ChatMemoryConfig.java` 配置 `MongoChatMemoryRepository`（集合 `ai_chat_memory`，自动建索引）+ `MessageWindowChatMemory`（窗口 20 条，始终保留 SystemMessage）；注入 `MessageChatMemoryAdvisor` 到 ChatClient；会话元数据实体 `entity/mongo/ChatSession.java`（集合 `chatSession`）+ `ChatSessionRepository`。
- 5-2 流式（已落地）：`ChatController`（3 端点）非流式 `POST /api/chat` + SSE `GET /api/chat/stream` + `POST /api/chat/stop`；SSE 事件流 `meta/chunk/tool_call/done/error`；`ChatService.stream` 返回 `Flux<String>` 并接入记忆 Advisor，含工具调用降级（ChunkMerger bug → .call() 非流式获取 → 分片模拟流式）。前端 `AiChatView.vue` 通过 `fetch` + `ReadableStream` 解析 SSE 事件，已联调通过。
- 5-3 会话（已落地）：`SessionController`（7 端点）会话列表/创建/查询/重命名/关闭/删除/清理过期；`SessionService` 维护 MongoDB `chatSession` 元数据（消息内容由 Spring AI 记忆库管理，不在此）。
- 验证：启动后访问 `GET /api/chat/stream?message=你好` 收到 SSE `chunk` 事件；多轮对话后历史被 `MessageWindowChatMemory` 保留（MongoDB `ai_chat_memory` 集合可见）；`GET /api/sessions` 返回会话列表。

### 阶段六：Tool Calling 与业务整合（技术点 3/7/8）✅ 已落地
- 6-1 工具 ✅ 已落地：`HabitQueryTools`（5 个 @Tool：今日记录/最近打卡/范围查询/按目标查询/会话列表）、`HabitStatTools`（4 个 @Tool：概览/达成率/趋势/雷达）、`GoalTools`（3 个 @Tool：列出目标/创建自定义目标/切换启用）、`HabitActionTools`（2 个 @Tool：内置维度打卡/自定义目标打卡）；通过 `MethodToolCallbackProvider` 注册到 `ChatClientConfig`。`system-prompt.st` 增加工具调用指引。
- 6-2 Advisor ✅ 已落地：新增 `agent/advisor/` 包，四个 Advisor 按 order 串接在 `ChatClientConfig.chatClient()` 的 `.defaultAdvisors(...)` 中：
  - `SafetyFilterAdvisor`（order=HIGHEST+10）：敏感词（越界医疗/违法/自伤）与超长输入（>4000 字符）前置拦截，命中直接返回合规话术，节省 Token。
  - `LoggingAdvisor`（order=HIGHEST+20）：记录 conversationId、用户输入摘要（截断 200 字）、响应耗时、Token 用量；自身异常不阻断。
  - `ContextInjectionAdvisor`（order=HIGHEST+100）：在用户消息前注入当前日期、星期、今日打卡概况（限长 200 字）；查询失败静默跳过。
  - `SafeRetrievalAdvisor`（order=HIGHEST+300）：阶段八组件，见下。

### 阶段七：趋势分析与图表
- 7-1 趋势统计 ✅ 已落地：`AnalysisController`（`/api/analysis`，4 端点）`/trends`、`/achievement`、`/overview`、`/radar`；`AnalysisService` 统计计算。
- 7-2 ECharts 可视化 ❌ 待完善：TrendView 渲染睡眠折线/运动柱状/饮水折线/达标率雷达，数据来自 `/api/analysis/*`。

### 阶段八：RAG 知识库（技术点 9）✅ 已落地
- **后端**：新增 `RagController`（5 端点：`/api/rag/import`、`/api/rag/upload`、`/api/rag/search`、`/api/rag/documents`、`/api/rag/documents/{id}`）、`RagService/Impl`。
  - 知识库语料位于 `src/main/resources/rag-docs/`：`sleep-guide.md` / `exercise-guide.md` / `diet-guide.md`。
  - `TokenTextSplitter` 分块（chunkSize=500，minChunkSizeChars=100）→ 注入 `doc_type` / `source` / `chunk_index` / `import_time` 元数据 → 由 `VectorStore.add()` 批量调用 `text-embedding-v3` 向量化 → 存入 MongoDB Atlas `habit_knowledge` 集合。
  - 列表查询通过 `MongoTemplate` 原生实现，并 `exclude("embedding")` 排除 1024 维向量字段。
  - `SafeRetrievalAdvisor` 内部委托 `RetrievalAugmentationAdvisor`（`VectorStoreDocumentRetriever` topK=3，similarityThreshold=0.5，`ContextualQueryAugmenter.allowEmptyContext=true`），对 `adviseCall` / `adviseStream` 全程 try-catch，异常时 WARN 并放行原始请求，保证 `/api/chat` 与 `/api/chat/stream` 在 Atlas 不可用时仍正常对话。
  - 新增 `VectorStoreProbe` 启动探针，非 Atlas 环境仅 WARN 但不阻断启动。
- **前端**：在 `AiChatView.vue` 内嵌 `KnowledgeDrawer.vue`（右侧抽屉），不新增页面路由/导航项；支持导入预设、拖拽上传、检索测试、文档列表与删除。
