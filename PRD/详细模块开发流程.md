## 〇、系统架构总览（已落地 + 规划）

### 架构分层

```
前端 frontend/ (Vue3 + Vite 单仓库 SPA)
  └─ Axios 调 /api + EventSource 收 SSE（Vite 代理 /api → 后端 8080）
            │
后端 habit-agent (Spring Boot 4.1 + Spring AI 2.0)
  └─ Controller 层（纯 REST/SSE）→ Service 层（业务）→ Repository 层
        ├─ JPA Repository → MySQL（业务数据：用户/习惯记录/目标）
        └─ Mongo Repository → MongoDB（AI 数据：对话记忆/分析结果/向量）
              └─ MongoDB Atlas VectorStore（RAG 知识库）
  └─ Agent 层（ChatClient + 工具 + Advisor + 多智能体路由）→ 通义千问 DashScope
```

## 二、阶段详解（已落地模块据实描述，待开发模块给出规范）

### 阶段一：环境搭建与项目骨架 ✅ 已落地
- 技术点：Spring Boot 4.1 + JDK 21 + Spring AI 2.0 BOM；Maven 多依赖（Web / JPA / MySQL / MongoDB / spring-ai-openai / mongodb-atlas-vector-store）。
- 双库就绪：MySQL `habit_agent` + MongoDB `habit_agent`（本地或 Docker）。
- 通义千问通过 DashScope OpenAI 兼容端点接入（application.yml `spring.ai.openai.base-url=https://dashscope.aliyuncs.com/compatible-mode`）。
- Git 仓库已初始化，远程 `https://github.com/Yu-xingyou/Agent_demo`。

### 阶段二：业务数据层（MySQL）✅ 已落地

#### 2-1 用户与习惯记录（HabitController，7 端点）
- Entity：`HabitRecord`（sleepTime/wakeTime/sleepDuration/sleepQuality/dietDesc/dietScore/exerciseType/exerciseDuration/waterIntake/mood/remark）。
- Repository：`HabitRecordRepository`（JPA，`uk_user_date` 唯一约束，每日打卡幂等）。
- Service：`HabitService`；Controller：`HabitController`（`/api/habits`，7 端点：今日/列表/按日期/创建/更新/删除/统计）。
- 验收：录入 → 查询 → 同日重复录入为更新。

#### 2-2 习惯目标管理（GoalController 目标 CRUD，8 端点）✅ 已落地
- **枚举（真实代码）**：
  - `goalType`：`SLEEP` / `EXERCISE` / `WATER` / `DIET` / **`CUSTOM`**（自定义目标，正式纳入 PRD 口径）。
  - `period`：`DAILY` / `WEEKLY` / `MONTHLY`（实体枚举；VO 通过 `.name()` 输出，前端按字符串展示）。
- **HabitGoalVO 字段**（与代码严格一致）：
  `id`、`userId`、`goalType`、`customName`（CUSTOM 时必填，目标名称）、`displayName`（CUSTOM→customName，其余→goalType 中文/枚举）、`targetValue`(BigDecimal)、`unit`、`period`、`isActive`、`createTime`、`updateTime`、`currentValue`（本周累计值）、`weeklyAchievement`（本周达成率 %）。
- Entity：`HabitGoal`（goalType VARCHAR、targetValue DECIMAL、unit、period 默认 DAILY、isActive）。
- 端点（`/api/goals` 前缀，8 端点）：列表 / 详情 / 创建 / 更新 / 删除 / 启用切换 / 活跃目标（含 CUSTOM）/ 按类型查询。
- 自定义目标特殊处理：`goalType=CUSTOM` 时由 `customName` 提供展示名，`displayName` 自动回退；`currentValue` 与 `weeklyAchievement` 由打卡记录聚合计算。
- 验收：创建 SLEEP 目标；创建 CUSTOM 目标（带 customName）；查询返回 displayName 与本周达成率。

#### 2-3 自定义目标打卡记录（GoalController `/api/goal-records`，6 端点）✅ 已落地【正式功能】
- **说明**：原为超纲扩展，现提升为正式功能模块（agent 模型「自定义习惯目标（可选）」的落地实现）。
- 端点（`/api/goal-records/records` 前缀，6 端点）：
  - `POST /api/goal-records/records`：录入/更新自定义目标打卡（`@Valid`：goalId、recordDate 必填）
  - `GET /api/goal-records/records/today`：今日所有自定义目标打卡
  - `GET /api/goal-records/records?startDate=&endDate=`：日期范围查询
  - `GET /api/goal-records/records/recent/{days}`：最近 N 天打卡
  - `GET /api/goal-records/records/goal/{goalId}/recent/{days}`：按目标查最近 N 天
  - `GET /api/goal-records/records/goal/{goalId}/achievement?period=WEEKLY`：按目标/周期查达成率（驱动 VO 的 `weeklyAchievement`）
- 请求体示例：
  ```json
  POST /api/goal-records/records
  { "goalId": 1, "recordDate": "2026-08-02", "value": 10000, "remark": "完成" }
  ```
- 验收：录入 CUSTOM 目标打卡 → 查询今日/范围 → 目标 VO 的 currentValue/weeklyAchievement 同步更新。

### 阶段三：前端工程（Vue3 + Vite 单仓库）✅ 已落地
- 5 路由：HomeView / CheckinView / HistoryView / TrendView / AiChatView。
- Axios 封装 `utils/request.js` 统一解析 `Result`；Vite `server.proxy['/api']` → `http://localhost:8080`。
- 打卡表单提交 `POST /api/habits`；历史页 `GET /api/habits`；首页今日统计 `GET /api/habits/today`。

### 阶段四：Spring AI 基础对接（技术点 1/2/4/6）❌ 待开发
- 目标：ChatClient Bean 配置、`defaultSystem` 设定「生活习惯助手」人格、通义千问连通验证。
- 产出：`ChatClientConfig`、prompts/system-prompt.st、ChatService 骨架（0 对外端点）。

### 阶段五：对话记忆与流式输出（技术点 5/11/12）❌ 待开发
- 5-1 记忆：`MongoChatMemoryRepository` 实现 `ChatMemoryRepository`，`MessageWindowChatMemory` 滑动窗口 20 条；ChatMessage/ChatSession 文档入 MongoDB。
- 5-2 流式：`ChatController`（3 端点）非流式 `POST /api/chat` + SSE `GET /api/chat/stream` + `POST /api/chat/stop`；前端 `chat-stream.js`（EventSource + 停止）。
- 5-3 会话：`SessionController`（7 端点）会话列表/创建/查询/删除/消息历史/关闭/重命名。

### 阶段六：Tool Calling 与业务整合（技术点 3/7/8）❌ 待开发
- 6-1 工具：`HabitQueryTools`（查历史/最近）、`HabitStatTools`（达成率/趋势）、`SuggestionTools`（保存建议到 Mongo）；注册到 ChatClient。
- 6-2 Advisor：`LoggingAdvisor`（请求/响应/Token 日志）、`SafetyFilterAdvisor`（输入过滤）、`ContextInjectionAdvisor`（业务上下文注入）。

### 阶段七：趋势分析与图表
- 7-1 趋势统计 ✅ 已落地：`AnalysisController`（`/api/analysis`，4 端点）`/trends`、`/achievement`、`/overview`、`/radar`；`AnalysisService` 统计计算。
- 7-2 ECharts 可视化 ❌ 待完善：TrendView 渲染睡眠折线/运动柱状/饮水折线/达标率雷达，数据来自 `/api/analysis/*`。

### 阶段八：RAG 知识库（技术点 9）❌ 待开发
- `RagController`（5 端点：导入预设/上传/检索/列表/删除）+ `RagService`（读取→`TokenTextSplitter` 分块→text-embedding-v3 向量化→Atlas 存储）。
- `RetrievalAugmentationAdvisor` 注入 Top-K 文档片段；Atlas 向量索引 `habit_vector_index`（`embedding` 字段）。

### 阶段九：多智能体路由（技术点 13）❌ 待开发
- `IntentRouter` 意图分类 → `DataAnalysisAgent` / `SuggestionAgent` / `ChatAgent`；ChatService 集成路由。

### 阶段十：AI 分析结果、提醒与收尾（技术点 14）❌ 待开发
- 10-1 `AiAnalysisController`（6 端点）：列表/详情/触发/删除/每日评价(`/daily` 含 score)/最新；`AiAnalysisDoc`（analysisType WEEKLY/MONTHLY/CUSTOM/DAILY + score + suggestion + riskWarning）。
- 10-2 `ReminderController`（5 端点）：CRUD + 启用切换；`Reminder` 实体（reminderTime/weekdays/reminderType 含 CUSTOM）。
- 10-3 边界：全局异常 19 码、限流、Token 截断、演示文档。
