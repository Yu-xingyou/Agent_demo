## 阶段二：业务数据层与基础 CRUD（MySQL）

### 子模块 2-1：JPA 实体与 Repository

**范围**：创建 4 个 JPA Entity + 4 个 Repository 接口，不含 Service 和 Controller。

**涉及文件**：
```
src/main/java/com/habit/agent/
├── entity/jpa/
│   ├── User.java                           # 用户实体
│   ├── HabitRecord.java                    # 习惯记录实体（核心业务表）
│   ├── HabitGoal.java                      # 习惯目标实体
│   └── Reminder.java                       # 打卡提醒实体
└── repository/jpa/
    ├── UserRepository.java                 # 用户 Repository
    ├── HabitRecordRepository.java          # 习惯记录 Repository
    ├── HabitGoalRepository.java            # 习惯目标 Repository
    └── ReminderRepository.java             # 打卡提醒 Repository
```

**详细说明**：

- `User.java`：
  - `@Entity @Table(name = "user")`
  - 字段：id（自增主键）、username（唯一）、nickname、createTime
  - `@PrePersist` 自动设置 createTime

- `HabitRecord.java`（核心实体，最复杂）：
  - 字段：userId、recordDate、sleepTime（LocalTime）、wakeTime、sleepDuration（BigDecimal，自动计算）、sleepQuality（1-5）、dietDesc、dietScore、exerciseType、exerciseDuration、waterIntake、mood、remark
  - `@PrePersist` 和 `@PreUpdate` 中自动调用 `calculateSleepDuration()`，根据入睡/起床时间计算睡眠时长
  - 跨天睡眠处理：如果起床时间早于入睡时间，加 24 小时

- `HabitGoal.java`：
  - 字段：userId、goalType（SLEEP/EXERCISE/WATER/DIET）、targetValue、unit、period、isActive、createTime、updateTime
  - `@PrePersist` 和 `@PreUpdate` 自动设置时间

- `Reminder.java`：
  - 字段：userId、title、reminderTime（LocalTime）、reminderType（SLEEP/DIET/EXERCISE/WATER/CUSTOM）、weekdays（String，逗号分隔如"1,2,3,4,5"）、isActive、createTime、updateTime
  - `@PrePersist` 和 `@PreUpdate` 自动设置时间

- Repository 接口（均继承 `JpaRepository`）：
  - `UserRepository`：`findByUsername`
  - `HabitRecordRepository`：`findByUserIdAndRecordDateBetweenOrderByRecordDateDesc`、`findByUserIdAndRecordDate`、`findByUserIdOrderByRecordDateDesc`
  - `HabitGoalRepository`：`findByUserIdAndIsActive`、`findByUserId`
  - `ReminderRepository`：`findByUserIdOrderByCreateTimeDesc`、`findByUserIdAndIsActive`

**验收标准**：
- [x] 项目启动后 MySQL 表结构与 Entity 匹配
- [x] 无编译错误

### 子模块 2-2：HabitService + GoalService + Controller + 公共组件 + 测试数据

**范围**：创建 Service 层、Controller 层（HabitController + GoalController）、公共组件（Result/异常处理/常量/VO）、测试数据初始化器。

**涉及文件**：
```
src/main/java/com/habit/agent/
├── common/
│   ├── result/Result.java                  # 统一响应封装
│   ├── exception/
│   │   ├── GlobalExceptionHandler.java     # 全局异常处理器（19 个错误码映射）
│   │   └── AiCallException.java            # AI 调用异常
│   ├── constant/AgentConstants.java        # 常量定义
│   └── vo/
│       ├── HabitRecordVO.java              # 习惯记录视图对象
│       └── HabitGoalVO.java                # 习惯目标视图对象
├── service/
│   ├── HabitService.java                   # 习惯记录业务（增删改查）
│   └── GoalService.java                    # 目标管理业务
├── controller/
│   ├── HabitController.java                # 习惯记录 REST API（7 端点）
│   └── GoalController.java                 # 习惯目标 REST API（6 端点）
└── config/
    └── DataInitializer.java                # 测试数据初始化（2周模拟打卡数据）
```

**详细说明**：

- `Result.java`：统一 API 响应 `{code, message, data}`，提供 `success()`/`error()` 静态方法
- `GlobalExceptionHandler`：捕获参数校验异常（400/40001）、日期范围异常（400/40002）、枚举值异常（400/40003）、记录不存在（404/40401-40406）、重复目标（409/40901）、AI 异常（503/50301-50303）、系统异常（500/50001-50003）
- `AgentConstants`：`DEFAULT_USER_ID = 1L`、MongoDB Key 前缀、TTL 时长等常量
- `HabitRecordVO`：习惯记录响应 VO（id/userId/recordDate/sleepTime/wakeTime/sleepDuration 等）
- `HabitGoalVO`：习惯目标响应 VO（id/userId/goalType/targetValue/unit/period/isActive/createTime）
- `HabitService`：
  - `saveOrUpdate()`：同一天重复打卡为更新（查 `uk_user_date`，存在则更新字段，不存在则新增）
  - `getRecordsByDateRange()`、`getRecentRecords()`、`getRecordByDate()`、`getAllRecords()`、`getTodayRecord()`
- `GoalService`：`getActiveGoals()`、`getAllGoals()`、`saveGoal()`、`getGoalByType()`、`updateGoal()`、`deleteGoal()`
- `HabitController`（`@RestController @RequestMapping("/api/habits")`，7 端点）：
  - `POST /api/habits`：录入/更新打卡
  - `GET /api/habits/today`：查询今日记录
  - `GET /api/habits?startDate=&endDate=`：按日期范围查询
  - `GET /api/habits/recent/{days}`：最近 N 天
  - `GET /api/habits/all`：所有记录
  - `GET /api/habits/{id}`：按 ID 查询
  - `DELETE /api/habits/{id}`：删除记录
- `GoalController`（`@RestController @RequestMapping("/api/goals")`，6 端点）：
  - `POST /api/goals`：创建目标
  - `GET /api/goals`：查询所有目标
  - `GET /api/goals/active`：查询启用目标
  - `GET /api/goals/{type}`：按类型查询
  - `PUT /api/goals/{id}`：更新目标
  - `DELETE /api/goals/{id}`：删除目标
- `DataInitializer`（`CommandLineRunner`）：
  - 启动时确保默认用户存在（username=demo）
  - 如果 `habit_record` 表为空，生成 14 天模拟打卡数据（随机睡眠时间/运动/饮水/心情）
