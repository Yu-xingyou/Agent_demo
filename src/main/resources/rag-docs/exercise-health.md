# 运动健康知识

## 每周运动建议
世界卫生组织建议成年人每周进行至少 150 分钟中等强度有氧运动，或 75 分钟高强度有氧运动，并配合每周 2 次以上的力量训练。中等强度的判断标准：运动时能说话但无法唱歌。

## 常见运动类型与强度
- 有氧运动：跑步、快走、游泳、骑行、跳绳，提升心肺功能。
- 力量训练：深蹲、俯卧撑、举铁，增强肌肉与骨骼。
- 柔韧训练：瑜伽、拉伸，改善关节活动度、降低受伤风险。
- 高强度间歇（HIIT）：短时高强度与低强度交替，燃脂效率高，适合有一定运动基础的人。

## 运动补水
运动前 2 小时饮水 400-500 毫升，运动中每 15-20 分钟补水 150-200 毫升，运动后按出汗量补充。长时间剧烈运动或大量出汗时，可补充含电解质的运动饮料。

## 运动损伤预防
1. 运动前充分热身（5-10 分钟动态拉伸）。
2. 循序渐进增加强度，每周增幅不超过 10%。
3. 选择合适的鞋和场地。
4. 运动后拉伸放松 5-10 分钟。
5. 出现关节疼痛、剧烈疼痛时停止运动并休息。

## 久坐人群的微运动
每坐 45-60 分钟站起来活动 3-5 分钟，如走动、伸展、靠墙静蹲。每天累计 8000-10000 步有助于维持基础活动量。
